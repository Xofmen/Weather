# Погода — анимированное приложение

Файлы: index.html, manifest.webmanifest, sw.js, иконки (icon-192.png, icon-512.png, apple-touch-icon.png).
Сборка не нужна: это обычные статические файлы.

## Как выложить (любой вариант, всё бесплатно)
1. Netlify Drop: откройте app.netlify.com/drop и перетащите всю папку. Ссылка готова за минуту.
2. GitHub Pages: создайте репозиторий, загрузите файлы, Settings → Pages → Deploy from branch (main, root).
3. Cloudflare Pages: Create project → Direct Upload → загрузите папку.

Нужен адрес с https (на всех трёх вариантах он есть): без него не работают геолокация и установка.

## Установка на iPhone
Откройте ссылку в Safari → кнопка «Поделиться» → «На экран Домой».

## Откуда погода
Open-Meteo (бесплатно, без ключа): прогноз и поиск городов. Город по умолчанию — Ташкент,
кнопка 📍 берёт вашу геолокацию.
